# Photo Shot List

This is the minimum photo record for a serious measurement pass. Every shot should include a feature ID reference and, when practical, the measuring tool in-frame.

## Session 1: global envelope

- front-left three-quarter view of full chassis
- rear-left three-quarter view of full chassis
- top view showing open side and surrounding edges
- side opening with ruler showing overall height
- side opening with ruler showing overall length
- top edge straight-on
- rear edge straight-on

## Session 2: OEM interface

- full lower rail from front
- lower rail front detail
- lower rail center detail
- lower rail rear detail
- top latch overall
- top latch engagement feature close-up
- rear top corner interface
- rear edge overlap or hook detail
- OEM cover thickness measured at interface zones
- any stamped beads, steps, or embosses that interrupt an otherwise flat fit assumption

## Session 3: GPU interference

- full GPU installed, side-on
- GPU highest point relative to chassis side plane
- GPU power connector close-up
- cable bend immediately after connector
- rear bracket and card length relationship
- any cooler protrusion or backplate bulge

## Session 4: PSU and cables

- external PSU current location, side view
- external PSU current location, top view
- current cable route from chassis to external PSU
- cable bundle compressed to realistic pass-through section
- largest terminated connector cluster next to ruler or calipers
- preferred cable exit zone marked with tape on the chassis or mock panel

## Session 5: install path

- panel install path mockup from bottom hook-in position
- interference at rear I/O or desk/wall clearance
- maximum practical top height indicated with cardboard or tape mockup
- any point where cables or connectors would have to be disconnected to remove the panel

## Naming rule

Use filenames that match the measurement sessions and feature IDs:

- `YYYYMMDD-s1-env-overall-01.jpg`
- `YYYYMMDD-s2-if-latch-02.jpg`
- `YYYYMMDD-s4-cbl-bundle-01.jpg`

## Quality rule

If a photo cannot support a later CAD argument, retake it immediately. A blurry reference photo is not a reference.
